# Live Mode 上架前检查 · 2026-11-09

范围是 1.0.2 的演出、歌曲库、歌单、踏板、启动与后台行为。Practice routine 属于下一版。

这些反馈用于选测，不代表本 App 出现同样故障。

## 已确认并修复

- 空绑定的首次使用页曾显示绑定已保存。现在只有真实存在的绑定才有保存说明。
- 冲突确认曾用一个合成的按下事件重新学习键，丢失确认前已松脚的信息。现在持续跟踪真实按下与释放，确认只更新映射。回归测试覆盖先松脚再确认和踩住确认两种情况。
- 移除了真机后台测试中指向早已删除的旧连接 Tab 的步骤。
- Build 63 的三个 Settings 图标使用 1×/2×/3× 透明素材。舞台纸单左上和右下贴胶带；歌曲库采用 C 收纳盒；双踏板中央有蓝牙刻印。按钮文字和 VoiceOver 标签仍由原控件提供。

## 测试证据

- iPhone 模拟器第一轮 42 个单元测试和 11 个界面用例通过。包括首次无设备绑定、6 个动作可用、后台退出学习、改绑取消、断开后的蓝牙指示、三种语言、深色演出模式、旧歌单迁移、共享曲目删除、42 首歌滚动和播放中编辑。
- 冲突修复后，iPhone 模拟器 43 个单元测试通过；六键学习路径、法语与德语辅助字号两个界面用例通过。首次播放设置用时 0.209 秒，为模拟器数值。
- iPad Air 11 英寸模拟器上，踏板与重新设计相关的 22 个单元测试、无设备学习界面均通过。
- Build 62 的 iPhone 14 Pro 真机五次启动到响应平均 0.316 秒，区间 0.306–0.327 秒。基础播放及设置通过；退到主屏 30 秒再返回，播放状态仍为运行，六个踏板动作可见。此检查读取 UI 状态，没有采集外部音频。
- 时钟回归包含模拟 600 秒中断后的节拍、渐进变速、静音小节对齐；没有用这项结果替代真实来电或耳机听测。

## 仍需真实器材的演出验收

用朋友实际的踏板和耳机记录型号、工作模式及系统版本。一次排练即可覆盖：

1. 绑定开始/停止，再改绑到另一个键；松脚后确认，下一脚必须生效。按住不得连跳。关闭再打开 App 后复用绑定。
2. 跑一首约十分钟的歌，开头、曲间停顿及静音小节结束时听清第一拍；切到前一首、下一首并核对速度。蓝牙输入延迟和耳机输出延迟分别记录。
3. 回主屏、锁屏，分别验证持续播放与能否重新启动。键盘/HID 翻页键只在 App 前台处理。媒体键与 MIDI 按实际设备实测后再写支持范围。
4. 分别测试响铃、接听、拒接、闹钟、耳机断开与重连。核实恢复后的节拍位置，以及应由用户手动恢复时不会自行出声。


## 最后复核

iPad 复测发现播放时编辑空备注未稳定取得键盘焦点。补齐备注框点击区域的焦点处理后，iPad 和 iPhone 模拟器均通过播放中输入备注、保存、前后切歌及重开验证。蓝牙状态界面测试中，真实 CoreMIDI 枚举曾覆盖模拟输入源；已将注入的拓扑与真实发现隔离，仅影响 Debug 测试。

Build 64 的歌单图案改为两角贴胶带的纸张，四行抽象笔迹。踏板页三态图为视觉提案。发布前仍需使用外部真实踏板验证锁屏、耳机声音和来电。
